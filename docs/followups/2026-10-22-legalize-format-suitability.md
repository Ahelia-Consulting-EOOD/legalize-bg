# Is the Legalize way of recording acts fully suitable for this corpus?

**Raised:** by the owner, 22 October 2026, in the write-path session of the run-design worktree, after reading the diagram of the reading and write path.

**The question:** this repository records each act the way the Legalize project does: one Markdown file with YAML frontmatter per act, and git history as the version record. The owner asks whether that form is fully suitable for what this corpus needs. The concern covers acts whose lex.bg text is wrong, acts whose history began before the Gazette's online archive, and annexes with tables or diagrams.

**Status:** recorded for later investigation only. By the owner's instruction, it is not part of the current discussion or plan.
