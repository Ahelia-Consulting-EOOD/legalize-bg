| D-016 | 2026-04-20 | `GIT_AUTHOR_DATE` formatted as ISO 8601 with time + timezone | Git rejects bare `YYYY-MM-DD` with "fatal: invalid date format" and exits 128 — discovered during the first Task 11 run, which silently bundled 3,573 files into 121 wrong-dated commits because the error was caught by the per-act try/except. `_format_author_date()` now emits `YYYY-MM-DDT00:00:00+00:00` and sets both `GIT_AUTHOR_DATE` and `GIT_COMMITTER_DATE` so `git log --before` reconstructs legislative history chronologically. | Active |
| D-017 | 2026-04-20 | Pre-1970 publication dates clamped to `1970-01-01` for `GIT_AUTHOR_DATE` | This git build refuses negative Unix timestamps in every input format (ISO 8601, RFC 2822, internal `@timestamp`). Many Bulgarian acts predate the epoch (1947 Amnesty Act, 1950s commercial codes). True publication date is preserved in the `Source-Date` body line; chronology of pre-1970 acts collapses to epoch but still orders them before any 1970+ act, which is the property that matters for `git log --before` queries. | Active |
| D-018 | 2026-04-20 | Bootstrap recovery via local replay, not re-crawl | When the date-format bug was found mid-run, the Markdown files on disk were already correct (the parsing pipeline worked; only `git commit` failed). `scripts/rebuild_bootstrap_commits.py` reads YAML frontmatter from each `.md`, resets the branch, and replays commits locally — 2 min 20 s for 3,573 commits vs ~2 hours for a clean re-fetch. Saved ~1h40min of lex.bg traffic and preserved the "one real lex.bg pass per bootstrap" discipline (bootstrap is meant to happen once, ever). | Active |
| D-019 | 2026-04-20 | `bootstrap/phase-1a` landed via `git push --force-with-lease` | Destructive push was acceptable because: (a) the branch is a feature branch, not `main`; (b) the force-with-lease safety check protects against clobbering unseen remote commits; (c) the broken pre-recovery state was tagged locally (`bootstrap-phase-1a-broken-backup`) for recovery if something went wrong during the replay. | Active |
