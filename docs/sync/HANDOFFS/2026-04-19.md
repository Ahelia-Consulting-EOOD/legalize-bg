## Critical Technical Facts for Implementation

### lex.bg Access (R1 findings — verified by actual testing)

```python
import requests
from bs4 import BeautifulSoup

# This is ALL you need. No Playwright, no cookies, no special headers.
url = "https://lex.bg/laws/ldoc/2136735703"  # ЗОП
resp = requests.get(url)
resp.encoding = 'cp1251'  # CRITICAL — not UTF-8
soup = BeautifulSoup(resp.text, 'html.parser')
```

- **URL pattern:** `https://lex.bg/laws/ldoc/{doc_id}`
- **Tree pagination:** `https://lex.bg/laws/tree/{category}/{page_index}` (0-based)
- **Categories:** `laws` (12 pages), `code` (1 page), `ords` (75 pages), `regs` (14 pages), `reg_laws` (2 pages)
- **Items per page:** ~35
- **Total acts:** ~3,574
- **Response time:** ~1.2s per page
- **Rate limiting:** None detected, but be polite (1 req/sec)
- **Encoding:** `windows-1251` — decode as `cp1251`

### CSS Classes for Parsing

| Class | Meaning |
|-------|---------|
| `.TitleDocument` | Law title |
| `.PreHistory` | Effective date |
| `.HistoryOfDocument` | Amendment history (all DV references) |
| `.Part` | Part (Част) |
| `.Heading` | Chapter (Глава) |
| `.Section` | Section (Раздел) |
| `.Article` | Article (Член) |
| `.TransitionalFinalEdicts` | ПЗР (transitional provisions — contain cross-law amendments!) |
