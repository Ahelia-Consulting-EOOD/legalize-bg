| extract#3 | (W2) Law is "an incrementally maintained system authored by distributed agents" requiring "stable fine-grained addresses for external reference." | extract#4 | (W2) Amendments are "typed operations" with components: "target address, action type, payload, and source provenance." Documented operations: Replace (node content update), Repeal (tombstone version preserving history), Insert (new node at specified position), Renumber (address change preserving identity), Text-replace/Text-repeal (substring-level). Amendments say "Section 12, subsection 2 is amended to read as follows." Locators: "path-based identifiers (e.g. §12(2)(c))"; parallels OIDs, Xanadu tumblers, ELI, FRBR, filesystems. "Renumber is an explicit operation because addresses are positional; renumbering is recorded to update external references." Authority: Finland Finlex = informational (compiler = independent verification oracle); Estonia Riigi Teataja IS authoritative; UK legislation.gov.uk = versioned, compiler does independent verification. | Q1, Q2, Q3 |
| extract#5 | (W3) 8-phase pipeline: "1 Acquire and archive source artifacts; 2 Parse amendment text into a clause surface; 3 Extract payloads and normalize source-locally; 4 Elaborate against live legal state (snapshot-pure); 5 Lower to canonical typed operations; 6 Replay over a base state; 7 Materialize point-in-time text; 8 Adjudicate against oracle or witness surfaces." "The pipeline separates lowering, target resolution, replay, and divergence accounting so that mismatches are inspectable rather than collapsed into a single opaque failure state." FI verbs: Repeal (kumotaan), Amend (muutetaan), Insert (lisätään). Clause surface = "A typed AST for amendment instruction language." Quirks mode = "marks every recovery path with provenance"; Strict mode = "forbids target guessing, hidden insertion anchoring, fallback replacement, ambiguous omission expansion, silent date estimation." | Q1, Q3 |
| extract#6 | (W4) Finland corpus: "690 fully replayable amended statutes" 1920s–2020s (1990s:107, 2000s:173, 2010s:237, 2020s:118). | extract#7 | (W5 README) Op verbs: system performs "replace, repeal, insert, renumber, move, delay commencement, restrict scope, and otherwise mutate a statute tree." 10-phase compiler: "1 acquire and archive source artifacts; 2 parse the operative source surface; 3 derive clause or effect surfaces; 4 extract and normalize payload shape; 5 elaborate targets against live legal state; 6 lower to canonical typed operations/effects; 7 replay over a statute tree; 8 compile timelines and materialize point-in-time law; 9 adjudicate replay against witness/oracle surfaces; 10 emit evidence, findings, and unresolved states." | extract#8 | (W6) Canonical ops. replace = "replace the content at the target address with the provided payload"; args target address + explicit IR subtree payload; precondition target must have substantive or tombstone/scaffold occupant; postcondition emits new version, must not duplicate siblings. insert = "add a new provision or child provision at the target address"; precondition exact slot absent OR occupied by non-substantive scaffold/tombstone; postcondition insertion ordering deterministic, consumes non-substantive occupant. repeal = "the targeted provision ceases to be in force as a substantive node"; payload None (tombstone-style); postcondition structural removal or tombstone replacement per jurisdiction policy. text_replace = "perform a constrained textual correction on an already targeted subtree … explicitly kept narrow; not a generic text editor." "future families like renumber/move only when semantics are explicit." | Q1, Operation taxonomy |
